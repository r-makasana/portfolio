# Portfolio Website

A modern, responsive portfolio website built with HTML, CSS, and JavaScript. Showcases projects, experience, skills, and contact for **Raj Patel** — Entry-Level Machine Learning Engineer.

---

## 🌐 Live Demo

- **[View Live Site](https://r-makasana.github.io/portfolio/)** — GitHub Pages
- **Local:** Open `index.html` in a browser or use a local server.

---

## 📂 Project Structure

```
portfolio/
├── index.html          # Main portfolio page
├── style.css           # Styling and animations
├── script.js           # Interactive features
├── thank-you.html      # Contact form success page
├── images/             # Images and media assets
│   └── profile.jpg    # Profile photo
├── assets/             # Additional resources
│   └── Resume_Raj.pdf  # Resume download
└── README.md
```

---

## 🛠️ Built With

- **HTML5**
- **CSS3** (Flexbox, Grid, Animations)
- **JavaScript** (ES6+)
- [**Font Awesome 6.5.1**](https://fontawesome.com/) — Icons
- [**Formspree**](https://formspree.io/) — Contact form

---

## ✨ Features

- Responsive design for all screen sizes
- Smooth scrolling navigation with active section highlight
- Animated background (grid + gradient orbs with parallax)
- Interactive contact form with Formspree
- Mobile-friendly hamburger menu
- Glassmorphism design style
- Scroll-triggered fade-in animations for sections
- Single-page layout: Intro, Projects, Experience, Skills, Education, Certification, Contact

## 🚀 Local Development

### Quick Start

1. **Clone the repository**

   ```bash
   git clone https://github.com/r-makasana/portfolio.git
   cd portfolio
   ```

2. **Open in browser**

   - Open `index.html` in your web browser, or  
   - Use a local server (e.g. `npx serve .` or `python -m http.server 8000`)

### Using VS Code Live Server

```bash
code .
# Right-click index.html → "Open with Live Server"
```

### Making Changes

1. Edit files in your code editor  
2. Test changes locally  
3. Commit and push to GitHub  

```bash
git add .
git commit -m "Your commit message"
git push origin main
```

GitHub Pages will automatically deploy your changes.

---

## 🎨 Customization

| Item           | Where to change |
|----------------|-----------------|
| **Images**     | Replace files in the `images/` folder (e.g. `profile.jpg`) |
| **Colors**     | Edit gradients and theme colors in `style.css` |
| **Content**    | Update text and sections in `index.html` |
| **Contact form** | Set your Formspree form ID in the form `action` in `index.html` |
| **Resume**     | Replace `assets/Resume_Raj.pdf` and update the download link if needed |
