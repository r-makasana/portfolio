## Running Locally

1. **Clone or download** this repo.
2. **Open in browser:**
   - Double-click `index.html`, or  
   - From the project folder: `npx serve .` or `python -m http.server 8000` and visit `http://localhost:8000`.
3. **Contact form:** Replace `your-form-id` in `index.html` with your [Formspree](https://formspree.io/) form ID so submissions work.

---

## Customization

- **Profile image:** Replace `images/profile.jpg` with your photo.
- **Resume:** Replace `assets/Resume_Raj.pdf` and update the download link if the filename changes.
- **Contact form:** Create a form at [Formspree](https://formspree.io/), then set the form `action` in `index.html` to your form endpoint.
- **Analytics:** Add your preferred analytics script in the `<head>` of `index.html` if needed.
