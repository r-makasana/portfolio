Honeypot Attack Classification & Forecasting

Python · Scikit‑Learn · ARIMA · LIME

Problem. Security teams needed a way to understand and anticipate attack patterns on honeypot systems to better allocate defense resources.

Solution. I trained Random Forest and XGBoost classifiers on honeypot traffic data to distinguish between types of attacks, then applied ARIMA to forecast future attack timing and protocols.

Tech. Python, Scikit‑Learn, XGBoost, ARIMA, and LIME for explainable AI to highlight which features most influenced predictions.

Outcome. Delivered a pipeline that not only classified attacks with high accuracy but also surfaced interpretable feature importance, helping teams prioritize defenses and monitoring rules.

Python · TensorFlow · AWS SageMaker

Solution. I built an end‑to‑end system that converts speech into text and generates concise summaries, dramatically reducing manual note‑taking effort.
